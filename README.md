# 🤖 Gen-AI Resume Analyzer

A full-stack AI-powered resume analyzer built using React, Node.js, Express, MongoDB and Google Gemini.

It analyzes a resume against a job description, provides a match score, identifies missing keywords, and gives AI-powered suggestions to improve the resume.
